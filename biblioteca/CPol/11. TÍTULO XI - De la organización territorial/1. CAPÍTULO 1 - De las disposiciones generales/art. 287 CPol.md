## Artículo 287

Las entidades territoriales gozan de autonomía para la gestión de sus intereses, y dentro de los límites de la Constitución y la ley. En tal virtud tendrán los siguientes derechos:

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-535-96 ; C-051-2001 ; C-089-2001 ; C-172-2001 ; C-540-2001 ; C-579-2001 ; C-648-2001 ; C-805-2001 ; C-811-2001 ; C-833-2001 ; C-837-2001 ; C-949-2001 ; C-1051-2001 ; C-1097-2001 ; C-1098-2001 ; C-1143-2001 ; C-1146-2001 ; C-1191-2001 ; C-1218-2001 ; C-1258-2001 ; C-066-03 ; C-208-03 ; C-251-03 ; C-385-03 ; C-477-03 ; C-105-04 ; C-532-05 : C-957-07 ; C-306-09 ; C-321-09 ; C-978-10 ; C-643-12 ; C-071-14 ; C-123-14 ; C-145-15 ; C-035-16 ; C-155-16 ; C-053-19 ; C-189-19 ; C-493-19 ; C-353A-21 ;

1\. Gobernarse por autoridades propias.

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-020-93 ; C-040-93 ; C-931-06 ; C-105-13 ; C-246-19 ; C-316-25 ;

2\. Ejercer las competencias que les correspondan.

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-765-06 : C-072-14 ; C-246-19 ; C-380-19 ; C-398-24 S.V; C-385-25 S.V;

3\. Administrar los recursos y establecer los tributos necesarios para el cumplimiento de sus funciones.

> [!note] Concordancias: Constitución Política; Art. [[art. 338 Ley 1386 de 2010|338]] Ley 1386 de 2010 Ley 1450 de 2011; Art. [[art. 11 Ley 2077 de 2021|11]] Ley 2077 de 2021 Ley 2392 de 2024

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-467-93 ; C-385-03 ; C-448-05 ; C-533-05 ; C-925-06 ; C-321-09 ; C-333-10 ; C-891-12 ; C-615-13 ; C-346-17 ; C-132-20 ; C-389-21 ; C-502-23 ;

4\. Participar en las rentas nacionales.

> [!note] Concordancias: Constitución Política de 1991; Art. [[art. 305 CPol|305]] ; Art. [[art. 315 Ley 60 de 1993|315]] Ley 60 de 1993 Ley 136 de 1994 Ley 388 de 1997; Art.
