## Artículo 40

Todo ciudadano tiene derecho a participar en la conformación, ejercicio y control del poder político. Para hacer efectivo este derecho puede:

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-517-92 ; C-588-92 ; C-020-93 ; C-487-93 ; C-086-94 ; C-089-94 ; C-562-2000 ; C-1345-2000 ; C-047-2001 ; C-093-2001 ; C-169-2001 ; C-292-2001 ; C-362-2001 ; C-477-2001 ; C-507-2001 ; C-540-2001 ; C-581-2001 ; C-709-2001 ; C-775-2001 ; C-915-2001 ; C-952-2001 ; C-955-2001 ; C-1052-2001 ; C-1147-2001 ; C-1168-2001 ; C-1212-2001 ; C-1256-2001 ; C-1258-2001 ; C-329-03 ; C-077-04 ; C-127-04 ; C-348-04 ; C-352-04 ; C-514-04; C-834-07 ; C-794-14 ; C-101-18 ; C-111-19 ; C-037-21 ; C-325-21 ;

1\. Elegir y ser elegido.

> [!note] Concordancias: Ley 5 de 1992; Art. [[art. 218 Ley 5 de 1992|218]] ; Art. [[art. 219 Ley 5 de 1992|219]] ; Art. [[art. 220 Ley 772 de 2002|220]] Ley 772 de 2002

2\. Tomar parte en elecciones, plebiscitos, referendos, consultas populares y otras formas de participación democrática.

3\. Constituir partidos, movimientos y agrupaciones políticas sin limitación alguna; formar parte de ellos libremente y difundir sus ideas y programas.

> [!note] Concordancias: Ley 130 de 1994 Ley 1475 de 2011

> [!note] Jurisprudencia Unificación: Consejo de Estado, Sección Quinta, Sentencia de Unificación, Expediente No. 11001-03-28-000-2014-00066-00b de 7 de septiembre de 2015, C.P. Dr. Alberto Yepes Barreiro.

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-003-93 ; C-020-93 ; C-089-94 ; C-199-94 ; C-283-95 ; C-226-96 ; C-157-98 ; C-371-2000 ; C-1159-2000 ; C-169-2001 ; C-955-2001

4\. Revocar el mandato de los elegidos en los casos y en la forma que establecen la Constitución y la ley.

> [!note] Concordancias: Ley 131 de 1994

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-532-93 ; C-011-94 ; C-180-94 ; C-179-2002;

5\. Tener iniciativa en las corporaciones públicas.

> [!note] Concordancias: Ley 5 de 1992; Art. [[art. 96 Ley 5 de 1992|96]] Inc. 3o.; Art. [[art. 218 Ley 5 de 1992|218]] ; Art. [[art. 219 Ley 5 de 1992|219]] ; Art. [[art. 229 Ley 5 de 1992|229]] Num. 2; Art. [[art. 230 Ley 5 de 1992|230]] Par.

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-513-92 ; C-544-92 ; C-016-93 ; C-131-93 ; C-132-93 ; C-264-96 ; C-562-2000 ; C-011-2001 ; C-949-2001 ; C-1113-2001 ; C-048-04 ; C-323-06 ; C-841-10 ; C-827-13 ; C-866-14 ; C-387-15 ; C-283-17 ; C-392-19 ; C-441-19 ; C-325-21 ;

7\. Acceder al desempeño de funciones y cargos públicos, salvo los colombianos, por nacimiento o por adopción, que tengan doble nacionalidad. La ley reglamentará esta excepción y determinará los casos a los cuales ha de aplicarse.

Las autoridades garantizarán la adecuada y efectiva participación de la mujer en los niveles decisorios de la Administración Pública.
