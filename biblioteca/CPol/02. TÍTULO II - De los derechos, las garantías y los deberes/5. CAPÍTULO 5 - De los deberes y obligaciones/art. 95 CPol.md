## Artículo 95

La calidad de colombiano enaltece a todos los miembros de la comunidad nacional. Todos están en el deber de engrandecerla y dignificarla. El ejercicio de los derechos y libertades reconocidos en esta Constitución implica responsabilidades.

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-127-93 ; C-131-93 ; C-136-93 ; C-155A-93 ; C-165-93 ; C-204-93 ; C-216-93 ; C-454-93 ; C-486-93 ; C-488-93 ; C-095-2001 ; C-431-2001 ; C-507-2001 ; C-551-2001 ; C-586-2001 ; C-711-2001 ; C-739-2001 ; C-816-2001 ; C-949-2001 ; C-974-2001 ; C-1178-2001 ; C-250-03 ; C-041-04 ; C-376-04 ;

Toda persona está obligada a cumplir la Constitución y las leyes.

Son deberes de la persona y del ciudadano:

1\. Respetar los derechos ajenos y no abusar de los propios;

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-540-93 ; C-542-93 ; C-565-93 ; C-099-2001 ; C-332-2001 ; C-1147-2001 ;

2\. Obrar conforme al principio de solidaridad social, respondiendo con acciones humanitarias ante situaciones que pongan en peligro la vida o la salud de las personas;

> [!note] Concordancias: Ley 986 de 2005 Ley 1035 de 2006 Ley 1436 de 2011 Ley 1505 de 2012 Ley 1523 de 2012 Ley 2454 de 2025; Art. [[art. 8 Ley 2454 de 2025|8]]

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-564-92 ; C-575-92 ; C-134-93 ; C-197-93 ; C-411-93 ; C-542-93 ; C-122-99 ; C-045-2001 ; C-332-2001 ; C-246-02 ; C-400-03 ; C-459-04 ; C-512-04 ; C-313-13 ; C-793-14; C-343-17 ;

3\. Respetar y apoyar a las autoridades democráticas legítimamente constituidas para mantener la independencia y la integridad nacionales.

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-075-93 ; C-058-94 ; C-511-94 ; C-519-94 ; C-048-2001 ;

4\. Defender y difundir los derechos humanos como fundamento de la convivencia pacífica;

> [!note] Concordancias: Ley 11 de 1992 Ley 199 de 1995; Art. [[art. 6 Ley 409 de 1997|6]] Ley 409 de 1997 Ley 985 de 2005

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-519-94 ;

5\. Participar en la vida política, cívica y comunitaria del país;

> [!note] Concordancias: Ley 80 de 1993; Art. [[art. 66 Ley 2042 de 2020|66]] Ley 2042 de 2020

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-415-93 ; C-099-2001 ; C-307-04 ; C-459-04 ; C-512-04

6\. Propender al logro y mantenimiento de la paz;

> [!note] Concordancias: Ley 104 de 1993 Ley 241 de 1995 Ley 368 de 1997; Art. [[art. 9 Ley 368 de 1997|9]] ; Art. [[art. 10 Ley 368 de 1997|10]] ; Art. [[art. 11 Ley 368 de 1997|11]] ; Art. [[art. 12 Ley 368 de 1997|12]] ; Art. [[art. 13 Ley 434 de 1998|13]] Ley 434 de 1998; Art. [[art. 4 Ley 438 de 1998|4]] , literal d Ley 438 de 1998 Ley 497 de 1999 Ley 1806 de 2016

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-075-93 ; C-077-93 ; C-169-93 ; C-266-93 ; C-267-93 ; C-268-93 ; C-415-93 ; C-464-93 ; C-048-2001 ; C-525-23 ;

7\. Colaborar para el buen funcionamiento de la administración de la justicia;

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-513-92 ; C-035-93 ; C-052-93 ; C-053-93 ; C-171-93 ; C-207-93 ; C-214-93 ; C-540-93 ; C-542-93 ; C-477-2001 ; C-552-2001 ; C-776-2001 ; C-893-2001 ; C-1104-2001 ; C-1149-2001 ; C-1287-2001 ; C-459-04 ; C-512-04

8\. Proteger los recursos culturales y naturales del país y velar por la conservación de un ambiente sano;

> [!note] Concordancias: Ley 99 de 1993; Art. [[art. 68 Ley 99 de 1993|68]] ; Art. [[art. 69 Ley 99 de 1993|69]] ; Art. [[art. 70 Ley 295 de 1996|70]] Ley 295 de 1996 Ley 296 de 1996 Ley 430 de 1998 Ley 491 de 1999 Ley 580 de 2000 Ley 1333 de 2009 Ley 2268 de 2022 Ley 1851 de 2017 Ley 2268 de 2022

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-204-93 ; C-379-93 ; C-530-93 ; C-059-94 ; C-318-94 ; C-423-94 ; C-519-94 ; C-459-04 ; C-512-04

9\. Contribuir al financiamiento de los gastos e inversiones del Estado dentro de conceptos de justicia y equidad.

> [!note] Concordancias: Constitución Política; Art. [[art. 363 Ley 43 de 1993|363]] Ley 43 de 1993; Art. [[art. 1 Ley 265 de 1996|1]] Ley 265 de 1996 Ley 621 de 2000

> [!note] Jurisprudencia Concordante: Corte Constitucional Sentencias de control de constitucionalidad: C-510-92 ; C-541-92 ; C-580-92 ; C-587-92 ; C-608-92 ; C-003-93 ; C-015-93 ; C-025-93 ; C-033-93 ; C-040-93 ; C-094-93 ; C-103-93 ; C-252-97 ; C-160-98 ; C-058-2001 ; C-096-2001 ; C-099-2001 ; C-170-2001 ; C-171-2001 ; C-804-2001 ; C-252-97 ; C-806-2001 ; C-1060A-2001 ; C-1064-2001 ; C-1107-2001 ; C-1144-2001 ; C-1179-2001 ; C-1251-2001 ; C-872-02 ; C-231-03 ; C-250-03 ; C-913-03 ; C-1017-03 ; C-229-04 ; C-374-04 ; C-459-04 ; C-461-04 ; C-475-04 ; C-512-04 ; C-536-06 ; C-833-13 ; C-743-15 ; C-388-16 ; C-010-18 ; C-060-18 ; C-088-18 ; C-120-18 ; C-514-19 ; C-486-20 ; C-057-21 ; C-059-21 ; C-061-21 ; C-389-23 ; C-489-23 ;
